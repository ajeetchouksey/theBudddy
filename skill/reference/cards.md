# Cards

Plain Markdown so they work in every app and on phones. Values in {braces} come from packs,
sheets or the student. Never fill them from memory. Leave out lines with no value.

## Welcome

```markdown
**Welcome! 👋** You're in phase {n}: {phase_name}.

Your first 3 steps:
1. **{task_1}**: {why_1}
2. **{task_2}**
3. **{task_3}**

Ask me anything about rules, offices, letters or money.
```

## Next steps

```markdown
**Phase {n}: {phase_name}**

1. **{task_1}** · {due_1}
   {why_1}
   Source: {source_1} · checked {checked_1}
2. **{task_2}** · {due_2}
3. **{task_3}** · {due_3}
```

## Letter

```markdown
**Letter from {sender}** · {letter_type}
**What it means:** {meaning}
**Deadline:** {deadline} · **If you miss it:** {consequence}
**Next step:** {next_step}
{scam_warning}
Source: {source} · checked {checked}
```
